# Shared reset confirmation component

`shared-reset-phone.png` shows the actual Settings reset section inside the UI modal at 375 × 812.
It explains personal Captain preservation, configured new-run capital and retired cash/wager
returns, and identifies the saved original run. The confirmation retries that original request.
After confirmation, the form is disabled until Settings is reopened against a fresh selection.

The preview uses a synthetic original reset record and receipt. No live island is reset, and the
image does not replace authenticated lifecycle or concurrent gameplay acceptance.
