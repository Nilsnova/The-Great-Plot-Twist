They do not establish naturally earned progression, conversion or economy balance. All actual role/build/research mutations use the real UI and API. No journal, HP, outcome or clock is replaced.

No full build/backend suite was rerun for these test-only additions. The relevant checks are the actual bounded browser invocations, source/helper guards, Node syntax and whitespace checks. Research reversal, demolition, reset/deletion, combat outcome and broad arsenal capacity claims must use their own separately qualified evidence; this partial invocation does not supply them.
