# Village selection and placement

Selection uses the village's brass palette. The corners stay on the selected wall's tile and render under building artwork. Move uses a continuous rim, sea green for a free cell and coral for a refused cell. The Move panel still describes the result in text. The selection dock shows known wall strength when live health is unavailable, without showing a live health meter.

The Chrome journeys started on the same village as main `db573347`. A real mouse click or touchscreen tap selected the wall. Tapping the occupied cell disabled Place. Tapping a valid cell enabled Place and saved only the selected wall's coordinates. Both wallet balances stayed fixed. The phone viewport used Chrome touch emulation with reduced motion and a device scale of 2.

The same touch scenario passed at 320 × 568, 844 × 390 and 768 × 1024. The visible selection actions stayed within the viewport and met a 44 × 44 CSS pixel target on each.

The visual references are [Clash Royale's ground target cue](https://www.youtube.com/watch?v=_hNxfiXmeAE&t=107s) and [the Clash of Clans village tour](https://www.youtube.com/watch?v=JkFBR05rlWE&t=405s).
