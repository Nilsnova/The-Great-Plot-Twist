## A practical rehearsal pass

1. On the actual presentation laptop, disconnect internet and open `index.html`
   from disk. Check first/last slide, arrows, click advance, every diagram, the
   paired speaker view and Print / PDF. This remains an outstanding direct-file
   gate because this cloud Chromium blocks `file:` by policy.
2. Extend the display. Keep the audience window on the projector and speaker
   notes on the laptop. Check that audience slides never show the notes.
3. Start the notes timer when speaking begins. Aim to reach the architecture
   exit at 3:00 and the lessons at 8:45. Pause only if rehearsal is interrupted.
4. Stop at the final handoff. Record the actual elapsed time below. Separately
   rehearse the transition into G11's live demo; this deck supplies no demo steps.
5. Leave the PDF available as a static fallback. Speaker notes and interactive
   navigation are in the HTML; the PDF is audience slides only.

For a **10:00** version, trim 10 seconds each from slides 2, 3, 7 and 8 and
5 seconds from the closing slide. Keep the safety/status qualifications. For a
slower delivery, there is 1:15 of room before the 12:00 upper bound; use it for
pointing at the diagrams and brief pauses, not a second demo.

## Export from a browser

The checked-in [PDF](The-Great-Plot-Twist.pdf) was generated by Chromium's print
renderer using this deck's `@media print` and `@page` rules. It contains ten
landscape 16:9 pages, one per slide. It has selectable text, original vector
diagrams and tagged structure. Speaker notes, controls and the timer are excluded.

On a desktop browser that permits printing:

1. Open `index.html`, then choose **Print / PDF** (or the browser's Print command).
2. Select **Save as PDF**, all pages, landscape, 100% scale and no margins. Use
   the CSS-defined page size where the browser offers it: 297 × 167.0625 mm.
3. Enable background graphics and disable browser headers/footers. Check that
   the preview has **10 pages** before saving. Printing works from any slide and
   from the notes view; all audience slides are included and notes are omitted.

To reproduce the automated export after frontend development dependencies are
installed, run from the repository root:

```sh
G25_PDF="$PWD/docs/presentation/The-Great-Plot-Twist.pdf" \
  node docs/presentation/check-deck.cjs
```

The harness uses `page.pdf` with `preferCSSPageSize`, backgrounds, tagging and
outlines enabled, and browser headers/footers disabled. Its default disk
interception makes no real network requests; see README for its scope and the
optional direct-file mode. Cloud policy disables the ordinary Print UI but
allows this headless browser export; neither policy was modified.

If content changes, regenerate the PDF and rerun its page-count/text checks so
the HTML and PDF continue to match. Do not include the notes in the exported
audience PDF or add story screenshots that might disclose a solution.
