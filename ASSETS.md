# Graphics asset register

All visual assets in this foundation are original procedural geometry written for this project. No model, texture, font, sound or image was downloaded from an asset library. The visual reference informed the general low-poly style only.

| Asset | Source | Licence / notes |
| --- | --- | --- |
| Terrain, paths, trees, rocks, flowers | `src/world/` | Original project code and geometry; no third-party art |
| Cottage, desk, boathouse, jetty, boat, lighthouse | `src/world/` | Original project code and geometry |
| Explorer character | `src/player/character.js` | Original project code and geometry |
| Sky, stars, waves, rain, lamp halo and beam | `src/world/` | Original procedural effects; no texture files |
| Lighthouse favicon | `public/favicon.svg` | Original SVG drawn for this project |
| Interface typography | Installed system fonts, with local fallbacks | No font files are distributed |
| Screenshots in `captures/` | Rendered from this application | Review evidence, not runtime assets |

Three.js, Vite and Vitest use the MIT licence. Playwright Core uses Apache-2.0 and is a development-only browser testing tool. Their package notices are distributed with the installed dependencies. Future external visual assets must be CC0 and listed here with their exact source URL and licence before use.
